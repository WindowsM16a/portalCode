# PortaCode 📱

Portable Gemini CLI Proxy for mobile coding.

## Setup
1. cd ~/Projects/portaCode
2. pnpm install:all
3. npm run dev

## Mobile Access
- Use Tailscale to access your laptop IP on port 3000.
- Default Master Key: porta-secret-key

## Features
- **Chat View**: Mobile-friendly streaming with interactive selection overlays.
- **Terminal View**: Full raw TTY for direct input.
- **Gemini Ready**: Automatically starts in your fleetlinq project directory.
